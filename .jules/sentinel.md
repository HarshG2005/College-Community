## 2024-05-24 - [ReDoS and Type DoS in Express Routes]
**Vulnerability:** User inputs (`req.query` and `req.body`) were passed directly to `String.prototype.toLowerCase()` and `new RegExp()` without explicit string casting and escaping in Express routes. This allows ReDoS via specially crafted strings with many regex metacharacters, and Denial of Service (DoS) by passing arrays or objects (Type DoS) causing string methods to fail.
**Learning:** `req.query` and `req.body` parameters from express are not guaranteed to be strings. An attacker can send `?type[$ne]=All` to pass an object, or `?type[]=foo` to pass an array. Express route parameters (`req.params`) are strings, but query and body are parsed by bodyParser/query parser which allows complex types.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to a string using `String()` before calling string methods. Furthermore, always escape regular expression special characters (`.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before passing them to the `RegExp` constructor.
