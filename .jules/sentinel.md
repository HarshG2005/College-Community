## 2024-05-18 - Type DoS and NoSQL Injection via Uncast Express Request Inputs
**Vulnerability:** Express route handlers (like `events.js` and `placements.js`) called string methods (e.g., `.toLowerCase()`) and used uncast variables (e.g., `req.query.search`, `req.query.company`) inside database queries or RegExp constructors. Passing object payloads (e.g., `?category[$ne]=val`) via queries caused Type DoS crashes, ReDoS via unescaped inputs in `RegExp`, or NoSQL injection.
**Learning:** Due to the lack of global security middleware casting inputs, request queries and bodies are parsed as objects, not strict strings. Calling string methods directly on them without casting or escaping leads to application crashes or injection attacks.
**Prevention:** Always manually cast all `req.query` and `req.body` parameters to `String` (e.g., `String(req.query.category)`) before calling string methods or injecting them into database queries, and properly escape any string destined for a RegExp constructor (e.g., `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
