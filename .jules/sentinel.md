## 2024-06-27 - [HIGH] Fix Type DoS and NoSQL injection in Express routes
**Vulnerability:** Type DoS and NoSQL injection were possible in `server/routes/events.js` and `server/routes/notices.js` because `req.query` parameters were not cast to Strings before being used in string methods like `.toLowerCase()` and MongoDB query objects like `$search`. Attackers could provide objects or arrays as query parameters to trigger crashes or bypass logic.
**Learning:** In Express, query parameters can be objects or arrays. Calling string methods on them directly, or passing them directly to MongoDB operators that expect strings, is a pattern of vulnerability throughout this application (as previously seen in `placements.js` and `auth.js`).
**Prevention:** Always explicitly cast `req.query` and `req.body` parameters to `String()` before using them in database queries (unless a different specific type like `Number` or `Date` is explicitly required and validated) and especially before calling string methods.
