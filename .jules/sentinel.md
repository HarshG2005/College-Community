## 2024-05-16 - Express Express Validator Array Bypass and Type DoS
**Vulnerability:** User inputs passed in `req.query` or `req.body` were directly having string methods like `.toLowerCase()` called on them, or were passed into Mongoose operators (like `$text: { $search: search }` or `new RegExp(company)`). `express-validator` allows arrays to pass `isEmail` if the first element is a valid email, allowing arrays to slip through and crash the server on `.toLowerCase()`. Passing objects into Mongoose queries creates NoSQL injection, and passing arrays/objects into `.toLowerCase()` crashes the server (Type DoS).
**Learning:** `express-validator` without `matchedData(req)` does not automatically cast validated fields to strings. Express query parameters and JSON body elements can be arrays or objects unless explicitly parsed as strings. Mongoose schemas handle casting for document creation, but not for raw queries like `$search`.
**Prevention:** Always explicitly cast `req.query` and `req.body` parameters to strings using `String(param)` before calling string methods or passing them into Mongoose queries that expect strings. Ensure regex inputs are explicitly escaped after string coercion to prevent ReDoS.
