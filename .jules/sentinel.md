## 2026-03-23 - ReDoS via Unescaped RegExp in Mongoose Queries
**Vulnerability:** User input from `req.query.company` was being passed directly to `new RegExp()` in a Mongoose query. This allowed a malicious user to craft a complex regex payload that could cause a Regex Denial of Service (ReDoS) attack when the database executed the query. Additionally, `req.query.type` was not cast to a string before calling `.toLowerCase()`, allowing for unhandled exception DoS if an object was passed in the query parameter.
**Learning:** In Mongoose, passing unescaped user input to `new RegExp` creates an avenue for database-level ReDoS. Additionally, Express `req.query` and `req.params` can be parsed as objects depending on the query string (e.g. `?type[foo]=bar`), so calling string methods directly on them without casting is unsafe.
**Prevention:** Always escape user input using `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` before using it in a `new RegExp` constructor. Always explicitly cast `req.query` and `req.params` values to a string via `String()` before calling string methods like `.toLowerCase()` or using them in string-specific operations.
