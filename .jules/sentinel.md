## 2024-05-24 - [DoS via uncasted inputs]
**Vulnerability:** Application crashed (Denial of Service) and allowed NoSQL injections when request query or body parameters (e.g., `req.query.category`, `req.body.email`) were passed as objects or arrays and subsequently had string methods like `.toLowerCase()` invoked directly on them. This happened in `server/routes/events.js`, `server/routes/notices.js`, `server/routes/placements.js`, and `server/routes/auth.js`.
**Learning:** Node.js Express framework does not automatically guarantee that query strings or body fields are strings; they can be parsed as objects. Calling `.toLowerCase()` on an object throws an unhandled exception if not caught properly, leading to application crash (DoS). In addition, objects used directly in regex (`new RegExp(company, 'i')`) without strict string conversion and escaping can cause ReDoS or NoSQL injections.
**Prevention:** Always explicitly cast incoming user input variables (e.g., `req.query`, `req.params`, `req.body`) to strings (e.g., using `String(param)`) before invoking string methods on them or using them in database queries (like inside `new RegExp` after proper escaping) to ensure type-safe handling.
