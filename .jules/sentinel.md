## 2025-01-20 - [Critical] Unsanitized express-validator input leading to Type DoS
**Vulnerability:** Input fields (like `req.body.email` and `req.query.category`) that are ostensibly "validated" by `express-validator` are not automatically cast to strings unless `matchedData(req)` is used. If an attacker passes an array (e.g., `?category[]=val` or `{"email": ["test@example.com"]}`), `.toLowerCase()` or other string methods will throw a `TypeError: X.toLowerCase is not a function`, leading to a Denial of Service (DoS) by crashing the application.
**Learning:** Even with robust validators like `isEmail()`, they might succeed or bypass validation for an array where the first element is a valid email, passing the raw array to the request handler. This is a common Express.js pitfall.
**Prevention:** Always explicitly cast user input parameters to `String(parameter)` before using string-specific methods, or ensure `matchedData` is used to safely extract validated input in Express routes.
