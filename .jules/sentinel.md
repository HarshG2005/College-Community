## 2024-08-27 - Mitigate Type DoS and NoSQL Injection in Express Routes
**Vulnerability:** Type DoS and NoSQL Injection (Critical/High). Express routes (`events.js`, `notices.js`, `materials.js`, `auth.js`) directly invoked string methods like `.toLowerCase()` on uncast `req.query` and `req.body` parameters, and passed uncast parameters into MongoDB `$text` queries. `express-validator` did not coerce matched fields without `matchedData`, leaving routes vulnerable to array or object inputs. Attackers could crash the server (DoS) by sending arrays/objects, or manipulate DB queries (NoSQL injection).
**Learning:** `req.query` and `req.body` parameters in Express are not guaranteed to be strings. Attackers can supply arrays (`?param=1&param=2`) or objects (`?param[$ne]=val`). Calling string methods on these types throws exceptions. Passing them uncast into database queries allows NoSQL injection.
**Prevention:** Always explicitly cast user inputs (e.g., `req.query`, `req.body`) to strings using `String(param)` before invoking string methods (like `.toLowerCase()`) or passing them into database queries, especially when dealing with `$text` search or dynamic query objects. Avoid assuming `express-validator` automatically coerces types without explicitly using `matchedData`.
