## 2026-08-16 - Prevent ReDoS and Type DoS in Mongoose Query Builder
**Vulnerability:** Unsanitized user inputs (`req.query.company`, `req.query.search`, `req.query.type`) in `server/routes/placements.js` were directly used in string methods (`.toLowerCase()`), object constructs (`$text: { $search: search }`), and dynamic Regular Expressions (`new RegExp(company, 'i')`). This enabled Type DoS (crashing via array payloads), NoSQL injection (via object payloads), and ReDoS (passing unescaped regex special characters).
**Learning:** Dynamic generation of `new RegExp()` with untrusted query string inputs in Express allows for ReDoS attacks which can severely impact performance or crash the service. Uncasted inputs can also bypass expected parameter types since Express parses objects/arrays in query strings.
**Prevention:** Always explicitly cast query parameters to String (e.g., `String(input)`) prior to calling string methods or passing to database drivers. Always escape regex special characters (e.g., `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before interpolating user input into `new RegExp()`.
