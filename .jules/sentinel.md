## 2025-02-14 - Fix ReDoS, Type DoS, and NoSQL Injection in Placements Routes
**Vulnerability:** The API endpoint `/api/placements` accepted `type`, `company`, and `search` queries from user input and used them dynamically in queries. `type` was passed to `.toLowerCase()` without type verification, leading to Type Denial of Service if an array or object was provided. `company` was passed to a new RegExp without escaping special characters, leading to a possible Regular Expression Denial of Service (ReDoS). `search` was used in `$text: { $search: search }`, leaving a potential avenue for NoSQL Object injection.
**Learning:** These types of issues consistently crop up when passing un-sanitized Express `req.query` attributes into string methods and database logic. We can't trust the type to be string.
**Prevention:** Always explicitly type-cast query parameters to string (`String(param)`). For RegExp parameters, explicitly cast to string AND escape Regex special characters (like `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
