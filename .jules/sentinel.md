## 2025-02-28 - Type DoS and NoSQL Injection via Uncast Route Parameters
**Vulnerability:** User inputs (`req.query` and `req.body`) in `server/routes/events.js`, `server/routes/notices.js`, `server/routes/materials.js`, and `server/routes/auth.js` were passed directly into `.toLowerCase()` or MongoDB queries (`$text`) without explicit string casting, leading to potential Type DoS (crashing the server if an array or object is passed and `.toLowerCase()` is called) and NoSQL object injection.
**Learning:** `express-validator` (e.g., `isEmail()`) can bypass validation for an array where the first element is a valid email, allowing arrays to slip through to the route handler. Without using `matchedData()` or explicit casting, this causes Type DoS. Additionally, Mongoose queries like `$text` require explicit casting for `search` parameters to prevent NoSQL object injection.
**Prevention:** Always explicitly cast user inputs (query/body parameters) to `String` (e.g., `String(param)`) before being used in Mongoose queries or string methods (like `.toLowerCase()`).
