## 2024-03-24 - [CRITICAL] Mongoose Regex ReDoS and NoSQL Injection
**Vulnerability:** Several Express routes passing query parameters directly into `new RegExp(req.query.param, 'i')` or using string methods (`toLowerCase()`) on raw `req.query` or `req.params` without explicit casting.
**Learning:** In Express, `req.query` and `req.params` can be parsed as objects/arrays if the client sends URLs like `?param[$ne]=val` or `?param=1&param=2`. This allows NoSQL object injection when passed to Mongoose, and crashes the Node.js server (DoS) when string methods like `.toLowerCase()` are called on them. Additionally, unescaped user input passed to `new RegExp` is vulnerable to ReDoS (Regular Expression Denial of Service).
**Prevention:** Always explicitly cast URL parameters to strings (`String(req.query.param)`) before using them in Mongoose queries or string methods. When using user input in Mongoose regex queries, ensure it is both explicitly cast to a string and safely escaped (`String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
