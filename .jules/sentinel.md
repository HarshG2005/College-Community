## 2024-05-24 - Uncast Query Parameters leading to Type DoS, ReDoS, and NoSQL Injection
**Vulnerability:** Express route handlers in `events.js`, `notices.js`, `materials.js`, and `placements.js` directly consume `req.query` properties (e.g., `search`, `category`, `type`, `company`) without explicitly casting them to strings. This exposes the application to Type Denial of Service (calling `.toLowerCase()` on an array), Regular Expression Denial of Service (ReDoS) when passing unescaped input to `new RegExp()`, and potential NoSQL Injection when passing objects to MongoDB queries like ``.
**Learning:** Express parses query string parameters into objects or arrays if they are formatted accordingly (e.g., `?param[key]=value` or `?param[]=value`). Using these values directly in string operations or database queries without type checking or casting is unsafe.
**Prevention:** Always explicitly cast `req.query` and `req.body` fields to strings (e.g., `String(param)`) before using them in string methods or database queries unless an object/array is explicitly expected and validated. Furthermore, always escape special characters in user input before passing it to `new RegExp()`.
