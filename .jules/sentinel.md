## 2024-05-24 - [HIGH] ReDoS and Type DoS in Placements Search
**Vulnerability:** The `/api/placements` endpoint accepts `company` and `type` via `req.query`. It directly invokes `.toLowerCase()` on `type` and passes `company` to a new `RegExp()` constructor without casting or escaping. An attacker could send arrays/objects as these query parameters causing server crashes (Type DoS), or send complex regex patterns in `company` causing a Regular Expression Denial of Service (ReDoS) or unintended matching behavior.
**Learning:** This is a recurring pattern in the codebase. Express parses URL query strings into JavaScript objects, not just strings. Calling string prototype methods or passing unescaped input to `RegExp` constructors directly on unvalidated `req.query` attributes is dangerous.
**Prevention:** All fields sourced from `req.query` or `req.body` must be explicitly cast to strings (e.g., `String(req.query.field)`) before calling string methods or executing logic. When building a RegExp from user input, always sanitize by escaping regex control characters using `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
