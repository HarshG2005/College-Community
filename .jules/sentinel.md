## 2024-05-31 - [Security] Prevent Type DoS, ReDoS, and NoSQL injection in Route Handlers
**Vulnerability:** Unsanitized user inputs from `req.query` and `req.body` were being used directly in MongoDB queries and with String methods (`toLowerCase()`) and `new RegExp()` calls. This allowed NoSQL injection via object payloads, and Denial of Service (DoS/ReDoS) by providing arrays/objects which lack these string methods or contain complex regex patterns.
**Learning:** Express middleware does not inherently ensure query or body fields are strictly Strings. Validating fields as non-empty via implicit truthiness is insufficient protection against Type DoS when malicious clients bypass frontend validation and send objects (e.g., `?category[$ne]=foo` or `?company[$regex]=.*`).
**Prevention:** Always explicitly cast variable inputs to `String` (e.g., `String(req.query.param)`) *before* applying string methods or using them in database queries to ensure predictable types. Escape regex special characters (using `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before dynamically constructing regex using `new RegExp()`.
