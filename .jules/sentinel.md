## 2026-06-17 - [ReDoS and Type DoS mitigation in Regex Queries]
**Vulnerability:** A vulnerability was discovered where unescaped user inputs from query strings (`req.query`) were passed to the `RegExp` constructor. This allowed attackers to craft inputs with expensive regular expressions causing a Denial of Service (ReDoS). Additionally, directly applying `.toLowerCase()` to `req.query` values without explicit casting allowed Type DoS because arrays passed via query strings would crash the app.
**Learning:** In Mongoose setups, Express route parameters directly fed into regular expressions must be explicitly cast to strings, and regex operators explicitly escaped. Using functions like `.toLowerCase()` directly on user inputs causes crashes (Type DoS) if the user passes an array payload like `?type[]=...`.
**Prevention:** Always explicitly wrap `req.query` or `req.body` inputs in `String(...)` before using string functions, and use a standard regex escape block (`.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before passing input into `new RegExp`.
