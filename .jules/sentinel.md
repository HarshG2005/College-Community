## 2024-05-24 - DoS and NoSQL Injection via Object Payloads in String Methods
**Vulnerability:** Express `req.query` and `req.body` inputs were being passed directly into `.toLowerCase()` and MongoDB `RegExp` operators. If an attacker passes an object (e.g. `?category[$ne]=null`) into a field expecting a string, `.toLowerCase()` on an object throws a TypeError, leading to an unhandled exception and 500 server crash (DoS). In cases where the query bypasses `.toLowerCase()`, it leads directly to NoSQL Injection. Passing unsanitized input to `new RegExp()` creates a Regex Denial of Service (ReDoS) vulnerability.
**Learning:** Never assume `req.query` or `req.body` variables are primitives. Express.js parses nested query strings into objects by default.
**Prevention:** Always cast variables extracted from `req.query` and `req.body` to strings using `String(param)` before performing string manipulations or database injections. Escape dynamic regex input using `String(param).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
