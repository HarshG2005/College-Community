## 2026-08-14 - Uncast Request Parameters Leading to Type DoS, ReDoS, and NoSQL Injection
**Vulnerability:** Express `req.query` properties were directly processed without type casting (e.g., calling `.toLowerCase()`, passing to `new RegExp()`, or using in `$text: { $search: ... }`). This allows attackers to send arrays or objects in the query string (e.g., `?type[]=val` or `?company[]=val`), leading to application crashes (Type DoS) when string methods are called on arrays, ReDoS if special regex characters are unescaped, and NoSQL injection if objects are passed to queries.
**Learning:** In Express, while `req.params` are inherently strings, `req.query` and `req.body` can be parsed as arrays or objects depending on the query string parser (like `qs`). Relying on truthiness checks (`if (company)`) is insufficient because objects and arrays are truthy.
**Prevention:** Always explicitly cast `req.query` and `req.body` fields to strings using `String(val)` before invoking string-specific methods or passing them to database queries where a string is expected. Additionally, always escape user input before using it to construct a `RegExp`.
