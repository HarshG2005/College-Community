## 2024-04-09 - [Fix ReDoS and DoS via Unsanitized Query Params]
**Vulnerability:** Express `req.query` and `req.params` parameters were used directly with `.toLowerCase()` and `new RegExp()` without casting to strings. An attacker could pass an array (e.g., `?type=a&type=b`) or an object (e.g., `?type[$ne]=value`), causing `.toLowerCase()` to throw an exception (DoS) or inject NoSQL queries. Additionally, unescaped input to `new RegExp()` allowed for Regular Expression Denial of Service (ReDoS).
**Learning:** In Node.js/Express, query parameters and route parameters are not guaranteed to be strings. They can be arrays or objects depending on the query string structure.
**Prevention:** Always explicitly cast `req.query` and `req.params` values to strings (e.g., `String(param)`) before invoking string methods like `.toLowerCase()` or passing them to `new RegExp()`. Always escape user input using `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` before using it in a regular expression.
