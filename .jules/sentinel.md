## 2024-05-24 - Uncast Inputs Lead to Type DoS, NoSQL Injection and ReDoS
**Vulnerability:** Across Express routes (e.g. `auth.js`, `placements.js`, `events.js`, `notices.js`, `materials.js`), user inputs from `req.body` and `req.query` were passed directly to database queries or string methods (like `.toLowerCase()` or `new RegExp()`) without explicit string casting. This allowed attackers to pass arrays or objects (e.g., `?type[]=1&type[]=2` or `?type[$ne]=All`) to bypass validation, crash the server (Type DoS) due to missing methods, cause NoSQL injections, or execute ReDoS attacks.
**Learning:** In the absence of global middleware coercing `req.query` and `req.body` values to strings, explicitly calling string methods on these objects assumes they are strictly primitive strings, which is not guaranteed.
**Prevention:** Always explicitly cast unverified `req.query` and `req.body` inputs to `String` and escape regex special characters before performing operations on them, particularly before calling string-specific methods or dynamically creating regular expressions.
