## 2024-10-24 - [ReDoS and NoSQL Injection via Uncasted Query Params]
**Vulnerability:** Express `req.query` and `req.params` inputs were being passed directly to `new RegExp()` without escaping regex metacharacters, leading to possible ReDoS attacks. Additionally, input like `?type[$ne]=foo` or `?category=arrayItem1&category=arrayItem2` was being passed directly to string methods (like `.toLowerCase()`) causing server crashes (DoS), or directly into Mongoose queries, potentially bypassing NoSQL query constraints.
**Learning:** By default, Express processes query string parameters as strings, arrays, or objects (e.g. nested objects). When passing user-controlled parameters into regex constructors or native string methods, a malicious input structure can cause application crashes or perform unexpected NoSQL operations.
**Prevention:** Always explicitly cast query or route parameters to a string (e.g., `String(req.query.param)`) when a string is expected, and use proper regex escaping (e.g., `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) on user input before constructing regular expressions dynamically.
