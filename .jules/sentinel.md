## 2026-09-12 - Prevent ReDoS and Type DoS in Express Route Handlers
**Vulnerability:** User inputs (`req.query.company`, `req.query.type`, `req.query.search`) were directly passed to Mongoose database queries (`new RegExp()`, `$search`) or string methods (`.toLowerCase()`) without explicit string coercion or sanitization. This allows attackers to send array/object payloads causing Type DoS crashes, and specially crafted regex payloads (e.g. `(((a+)+)+)+$`) causing Catastrophic Backtracking (ReDoS).
**Learning:** Even internal API query parameters require strict type enforcement and sanitization before being evaluated as regular expressions or string functions to prevent availability and injection attacks.
**Prevention:** Always explicitly coerce `req.query` and `req.body` parameters to `String()` before passing them to string prototype methods or database operations. If constructing a `RegExp` from user input, always escape regex special characters first using `string.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
