## 2024-10-24 - Express Query Parameter Type DoS and ReDoS Vulnerability Pattern
**Vulnerability:** User inputs from `req.query` (like `type`, `company`, `search` in `placements.js`) were used directly in string operations (`.toLowerCase()`), regex construction (`new RegExp()`), and MongoDB `$text` search without explicit type casting.
**Learning:** In Express, `req.query` parameters can be parsed as objects or arrays instead of strings (e.g., `?type[$ne]=something`). Calling string methods like `.toLowerCase()` on an array throws a TypeError, leading to an unhandled exception and a Denial of Service (Type DoS). Passing untrusted user input directly to `new RegExp()` can cause Regular Expression Denial of Service (ReDoS), and passing objects to MongoDB queries can cause NoSQL injection.
**Prevention:** Always explicitly cast `req.query` and `req.body` parameters to `String` (e.g., `String(req.query.param)`) before calling string methods or using them in database queries. When constructing a RegExp from user input, additionally escape regex special characters (e.g., `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
