## 2024-05-24 - Uncast req.query and req.body inputs leading to Type DoS and NoSQL Injection
**Vulnerability:** Type DoS and potential NoSQL injection vulnerabilities were present across multiple route handlers (`auth.js`, `events.js`, `notices.js`, `placements.js`, `materials.js`). The code was calling string methods like `.toLowerCase()` on uncast user inputs (e.g., `req.query.category.toLowerCase()`) or passing them directly to Mongoose queries (e.g., `query.$text = { $search: search }`).
**Learning:** In Express, while `req.params` are guaranteed strings, `req.query` and `req.body` fields can be arrays or objects (e.g., if an attacker sends `?category[$ne]=1`). Calling string methods on these objects causes `TypeError` (Type DoS), and passing them to queries can allow NoSQL injection.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to a String (e.g., `String(input)`) before applying string methods or using them in database queries, or use rigorous validation middleware to enforce types.
