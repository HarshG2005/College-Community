## 2024-05-05 - Missing Input Sanitization in RegExp and String Methods
**Vulnerability:** Express route parameters and query fields (e.g., `req.query.company`, `req.query.type`) are directly passed to string methods (`toLowerCase()`) and RegExp constructors (`new RegExp(company, 'i')`) without type checking or escaping. This allows Type DoS (crashing the server by passing objects/arrays instead of strings) and ReDoS/NoSQL Injection (passing crafted regex patterns to MongoDB).
**Learning:** In applications lacking global validation middleware, input data from `req.query`, `req.params`, or `req.body` must never be trusted. Passing an array like `?type[]=foo` crashes `type.toLowerCase()`. Passing a pattern like `?company=.*.*.*.*` to `new RegExp` causes catastrophic backtracking.
**Prevention:** Always explicitly cast inputs to `String()` before invoking string methods. When using user input in regex Mongoose queries, it must be escaped first, e.g., `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
