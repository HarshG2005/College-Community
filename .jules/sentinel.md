## 2024-05-18 - Prevent NoSQL Injection and Type DoS in Express Route Handlers
**Vulnerability:** Uncast user inputs (from `req.query` and `req.body`) were passed directly into Mongoose queries (enabling NoSQL injection via object payloads) or subjected to string methods like `.toLowerCase()` (causing Server-Side DoS via unhandled `TypeError`s when receiving arrays or objects).
**Learning:** `express-validator` rules like `isEmail()` do not automatically cast inputs to strings unless `matchedData` is explicitly used, allowing arrays containing a valid email at index 0 to bypass validation and subsequently crash the application when `.toLowerCase()` is called on them. Furthermore, MongoDB implicitly interprets uncast input objects leading to query operator injection (e.g., `{$ne: null}`).
**Prevention:** Always explicitly cast user-supplied data to a `String` (e.g., `String(req.body.email)`) *before* applying any string manipulations or querying the database, effectively neutralizing both NoSQL injection vectors and type-based crashes.
