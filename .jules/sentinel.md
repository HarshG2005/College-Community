## 2024-10-27 - [Fix Type DoS and NoSQL Injection in Express Routes]
**Vulnerability:** Type DoS and NoSQL injection vulnerabilities exist across multiple Express routes due to passing uncast `req.query` and `req.body` parameters directly to string methods (like `.toLowerCase()`, `new RegExp`) and database queries (like `$text: { $search }`). Attackers can send these parameters as objects or arrays instead of strings (e.g. `?category[$ne]=something`, `?email[]=user@example.com`), crashing the server or bypassing/manipulating database queries.
**Learning:** Even with basic validation, route parameters parsed by Express (`req.query`, `req.body`) can be arrays or objects instead of strings. Methods like `.toLowerCase()` expect a string and will throw an error if called on an object/array, causing a Denial of Service. Passing uncast objects to MongoDB queries can result in NoSQL injection.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to strings (e.g., using `String(param)`) before calling string methods or passing them to database queries. Additionally, escape variables passed into `new RegExp` to prevent ReDoS.
