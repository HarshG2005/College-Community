## 2024-09-05 - Mitigate Express Type DoS and NoSQL Injection via Array/Object Payloads in req.query
**Vulnerability:** Express parses query strings (like `?category[$ne]=All` or `?search[]=foo`) into objects or arrays. Directly invoking string methods like `.toLowerCase()` on unvalidated `req.query` parameters throws TypeErrors, causing the server to crash (Denial of Service). Furthermore, passing these uncast objects directly into Mongoose queries allows NoSQL injection.
**Learning:** `req.query` and `req.body` parameters in Express are not guaranteed to be strings. The lack of strict type validation before usage (especially before string method calls or database queries) is a widespread pattern in this codebase.
**Prevention:** Always explicitly coerce `req.query` and `req.body` parameters to String using `String(param)` before performing string operations (like `.toLowerCase()`) or passing them into Mongoose queries. This neutralizes NoSQL injection operators (converting them to the harmless `"[object Object]"`) and prevents DoS crashes. Express route parameters (`req.params`), however, are inherently strings.
