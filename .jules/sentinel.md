## 2024-10-24 - Express Uncast `req.query` leading to ReDoS and Type DoS
**Vulnerability:** In Express routes, extracting user inputs from `req.query` without explicitly casting them to strings can lead to Type Denial of Service (DoS) and Regular Expression Denial of Service (ReDoS). If an array or object is passed via the query string (e.g., `?type[]=foo`), calling string methods like `.toLowerCase()` on it will crash the server. Additionally, passing an unescaped string to `new RegExp()` can cause ReDoS, and passing an uncast object to a `$text` `$search` MongoDB query can lead to NoSQL injection.
**Learning:** `req.query` values can be objects or arrays in Express, not just strings. Express route parameters (`req.params`) are strictly strings, but query parameters and request bodies are not.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to strings (e.g., `String(req.query.param)`) before calling string methods or using them in database queries. Always escape strings before using them in `new RegExp()`.
