## 2026-10-09 - [Express Route String Methods DoS and Injection]
**Vulnerability:** Type DoS, ReDoS, and NoSQL injection vulnerabilities exist across multiple Express routes (events, notices, materials, placements, auth) due to invoking string methods (like `.toLowerCase()`) or passing variables into `new RegExp()` directly on `req.query` or `req.body` inputs without strict type checking or coercion.
**Learning:** The application lacks global middleware to sanitize inputs against array or object pollution. Even if validation libraries (like express-validator) check fields, the underlying data inside `req.body` may still be accessed natively as an array or object, leading to crashes when string methods are called or bypasses when NoSQL injection patterns are evaluated.
**Prevention:** Always explicitly cast user input (`req.query` and `req.body`) to a string (e.g., `String(value)`) before calling string methods on them or querying the database. Also, explicitly escape any user input used dynamically within a `RegExp` to prevent ReDoS.
