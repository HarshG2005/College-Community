## 2024-05-18 - Prevent Type DoS and NoSQL Injection via Express req.query
**Vulnerability:** Uncast `req.query` variables (which can be objects or arrays if the query string is formatted like `?param[$ne]=val` or `?param=1&param=2`) were being passed directly to string methods like `.toLowerCase()` and Mongoose queries like `$text: { $search: param }`. This exposes the application to Type Denial of Service (DoS) crashes and NoSQL injection vulnerabilities.
**Learning:** In Express, unlike `req.params` which are always strings, `req.query` and `req.body` parameters can be parsed as objects or arrays. Calling string methods on these directly without validation or casting will crash the server. Passing them uncast to Mongoose queries allows malicious object structures to be injected.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to a `String` (e.g., `String(req.query.param)`) before calling string methods or passing them to Mongoose `$text` or regex queries. Express route parameters (`req.params`) are already inherently strings and do not strictly require casting.
