## 2025-02-28 - [CRITICAL] Uncast Parameters Causing Type DoS and NoSQL Injection
**Vulnerability:** Express application was receiving user inputs (like `req.body.email` and `req.query.search`) without explicitly casting them to String before calling string methods (e.g., `.toLowerCase()`) or passing them directly to Mongoose queries (e.g., `new RegExp(...)`, `{ $text: { $search: query } }`). Attackers could pass arrays or objects to trigger Denial of Service crashes (Type DoS) or NoSQL injections.
**Learning:** In Express, `req.query` and `req.body` parameters are parsed natively but are not guaranteed to be strings. A malicious array passed in the payload bypasses `typeof string` assumptions and crashes the node process when string methods are invoked, or alters the query logic if passed into NoSQL statements.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to strings using `String(value)` before calling string methods or injecting them into database queries, and escape RegEx specials appropriately to avoid ReDoS.
