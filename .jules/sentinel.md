## 2024-03-01 - ReDoS vulnerability in placement route
**Vulnerability:** Regular Expression Denial of Service (ReDoS) due to unescaped user input passed directly to the `RegExp` constructor in `server/routes/placements.js` (`new RegExp(company, 'i')`). This allows attackers to submit complex regex patterns that crash the server or cause high CPU utilization. Furthermore, NoSQL Injection and Type DoS issues existed due to calling `.toLowerCase()` on the uncast `type` query parameter, and passing an uncast `search` query parameter.
**Learning:** Even simple regex-based substring searches (like `new RegExp(company, 'i')`) are susceptible to ReDoS if the user can inject unescaped regex special characters (like `.*+?^${}()|[]\`). Additionally, Express `req.query` and `req.body` parameters can be objects or arrays, so calling string methods on them or passing them to mongoose queries without validation can lead to crashes or query injection.
**Prevention:** Always escape regex special characters using a pattern like `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` before passing user input to `new RegExp()`. Always explicitly cast inputs to Strings (e.g. `String(req.query.type)`) before calling string methods or passing them to database queries.
