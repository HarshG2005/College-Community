## 2024-05-24 - [Express req.query ReDoS, Type DoS, and NoSQL Injection]
**Vulnerability:** Calling string methods like `.toLowerCase()` or passing values to `new RegExp()` directly from uncast `req.query` parameters in Express routes exposes the application to Type DoS (crashing the server if an object/array is passed) and ReDoS (if regex characters are not escaped). Passing uncast `req.query` variables directly into MongoDB `$text: { $search: query }` exposes the application to NoSQL injection.
**Learning:** `req.query` and `req.body` parameters in Express are not guaranteed to be strings. An attacker can pass query parameters as objects or arrays (e.g., `?type[]=foo` or `?company[$ne]=bar`). Calling `.toLowerCase()` on an array throws an error (Type DoS). Unescaped regex characters can lead to ReDoS.
**Prevention:** Always explicitly cast `req.query` and `req.body` parameters to strings using `String(param)` before performing string operations, applying regex, or using them in database queries. Also, escape regex special characters (using `replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before passing user input to `new RegExp`. Preserve original truthiness checks (`if (search)`) rather than strict undefined checks to properly handle empty string query parameters.
