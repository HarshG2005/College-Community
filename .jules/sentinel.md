## 2024-07-01 - Type Confusion DoS and NoSQL Injection in Express Routing
**Vulnerability:** Application-crashing Denial of Service (DoS) and potential NoSQL object injections existed because inputs from `req.query` and `req.body` were used directly in string operations (e.g., `.toLowerCase()`, `new RegExp()`, `$search`) without validation or type casting. For example, `{"email": ["test@test.com"]}` passed `express-validator` but crashed the server on `email.toLowerCase()`. Similarly, ReDoS could occur from unescaped object inputs.
**Learning:** `express-validator` does not coerce valid elements in arrays into scalar strings when referencing the original `req.body` directly. Express body parser frequently parses inputs as objects/arrays if formatted as such, causing type confusion.
**Prevention:** Always manually cast `req.query` and `req.body` fields to strings (e.g., `String(val)`) *before* invoking string methods or using them in regex/database filters, ensuring robust Type DoS and NoSQL injection protection.
