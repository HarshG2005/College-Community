## 2024-08-31 - Patching Type DoS and ReDoS vulnerabilities in Express routes
**Vulnerability:** Calling string methods like `.toLowerCase()` and creating a `new RegExp()` directly on uncast Express `req.query` parameters, which can be arrays or objects (e.g. `?type[$ne]=something`). This allows attackers to cause unhandled exceptions leading to Denial of Service (Type DoS) or execute computationally expensive queries (ReDoS / NoSQL Object Injection).
**Learning:** `req.query` and `req.body` values are not guaranteed to be strings. An attacker can send an array or object in the query string or request body. When string methods like `toLowerCase()` are called on these unexpected objects, an error is thrown which crashes the route handler if it is not caught or handled properly. Also, passing unsanitized and uncast input to `new RegExp()` exposes the endpoint to Regular Expression Denial of Service (ReDoS).
**Prevention:** Always explicitly cast user input parameters to String (e.g., `String(req.query.type)`) before calling string methods or passing them to the database. When constructing regular expressions from user input, use a regex escaping function (e.g., `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) to neutralize special regex characters.
