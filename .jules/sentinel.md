## 2024-05-18 - [Type DoS, ReDoS, and NoSQL Injection via Express Query Parameters]
**Vulnerability:** Express `req.query` variables (`type`, `company`, `search`) were passed directly to string methods (`.toLowerCase()`), `RegExp` constructors, and Mongoose queries (`$text: { $search: search }`). This allows malicious users to send arrays or objects in the query string, leading to Type DoS (crashing the server on string methods), ReDoS (via unescaped regex metacharacters), or NoSQL Injection (via object injection).
**Learning:** In Express, query strings and body payloads are not strictly strings; they can be parsed as objects or arrays. Mongoose handles basic casting, but direct usage of these variables in custom logic (regex, string methods) without explicit string casting opens multiple attack vectors.
**Prevention:** Always explicitly cast user inputs from `req.query` and `req.body` to strings (e.g., `String(input)`) before calling string methods or passing them to potentially dangerous functions like `new RegExp()`. For regex, ensure metacharacters are properly escaped.
