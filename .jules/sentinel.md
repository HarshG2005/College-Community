## 2024-06-25 - ReDoS and Type DoS in Express Route Query Parameters
**Vulnerability:** Unsanitized user inputs from `req.query` (like arrays or objects) were being passed directly to string methods (`toLowerCase()`) and constructors like `new RegExp()`. Passing an array or object to `.toLowerCase()` causes a TypeError and crashes the Node.js server (Type DoS). Passing unescaped input to `new RegExp()` creates a Regular Expression Denial of Service (ReDoS) vulnerability.
**Learning:** Due to the lack of global input sanitization middleware, `req.query` and `req.body` parameters are parsed by Express/qs and can be objects/arrays (e.g., `?category[]=val`). This codebase pattern passes them directly into MongoDB queries or string methods without validation, leading to critical DoS.
**Prevention:** Always explicitly cast variables extracted from `req.query` and `req.body` to strings using `String(param)` *before* calling string methods. Always escape regex special characters (e.g., using `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) when dynamically constructing a `RegExp` object from user input.
