## 2024-05-24 - DoS and NoSQL Injection via Uncast `req.query` Parameters
**Vulnerability:** Denial of Service (DoS) and potential NoSQL Injection due to uncast `req.query` parameters being used in string methods (like `.toLowerCase()`) and direct `new RegExp()` queries in Mongoose. If a user passes an object instead of a string (e.g., `?category[$ne]=val`), `.toLowerCase()` will throw a TypeError, crashing the request and potentially the server. Unsanitized strings passed to `new RegExp()` cause Regular Expression Denial of Service (ReDoS).
**Learning:** Express `req.query` parses objects when nested brackets are used in the query string. Without explicitly casting these properties to strings before applying string operations or regex construction, the application is vulnerable.
**Prevention:** Always explicitly cast `req.query` (and `req.params`) values to strings (e.g., `String(param)`) before using them in string methods. Always sanitize and escape string inputs before using them in `new RegExp()` queries to prevent ReDoS.
