## 2024-05-24 - Regex DoS and NoSQL Injection via Unsanitized `req.query`
**Vulnerability:** User input from `req.query` (e.g., `company` in placements search) was directly passed to `new RegExp(company, 'i')` without escaping regex special characters. Additionally, `req.query` parameters were not explicitly cast to strings before calling `.toLowerCase()` or being used in Mongoose queries, allowing NoSQL injection via object payloads (e.g., `?type[$ne]=All`).
**Learning:** In Express.js applications using Mongoose, `req.query` parameters can be parsed as objects instead of strings if submitted in a specific format (e.g., `?param[$ne]=value`). Directly using these parameters in string methods (like `.toLowerCase()`) causes a TypeError (DoS). Furthermore, passing unescaped user input to `new RegExp` allows Regex Denial of Service (ReDoS) attacks.
**Prevention:** Always explicitly cast user input from `req.query` or `req.params` to strings (e.g., `String(param)`). For search queries using `new RegExp`, strictly escape regex special characters using a utility function (e.g., `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
