## 2024-05-24 - [Missing Global Security Middleware Risk]
**Vulnerability:** Widespread missing type casting of `req.query` and `req.params` allowing objects to be passed (e.g., `?param[$ne]=val`), combined with unsafe regex instantiation `new RegExp(req.query.param)`.
**Learning:** The application lacks global security middleware (like Express validation or manual sanitizers across all route parameter payloads), meaning every route must manually and explicitly cast its input parameters to `String`. Without this, type confusion can cause DoS crashes on `.toLowerCase()`, NoSQL injection via MongoDB query operators, and ReDoS attacks via unescaped string patterns in RegExp.
**Prevention:** Always enforce explicit type casting `String(req.query.param)` and escape regex metadata `String(param).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` prior to database queries. Consider creating a centralized validation utility/middleware in `server/middleware/security.js` for widespread sanitization and input validation.
