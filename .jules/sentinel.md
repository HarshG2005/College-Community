## 2024-09-25 - Fix Type DoS, ReDoS, and NoSQL Injection across multiple routes
**Vulnerability:** Several Express routes (`server/routes/placements.js`, `events.js`, `notices.js`, `materials.js`, `auth.js`) failed to cast `req.query` and `req.body` parameters to `String` before applying string methods like `.toLowerCase()` and creating `new RegExp()`. This allowed NoSQL injection via object payloads (`?search[$ne]=`), ReDoS via unescaped special characters in regexes (`?company=.*`), and Type DoS because `.toLowerCase()` throws an error on non-string inputs (e.g., arrays or objects like `?category=1&category=2`).
**Learning:** `express-validator` and basic destructuring do not automatically coerce inputs into Strings. Mongoose `req.query` payloads can easily be cast into arrays or objects in Express, causing string methods to crash the application, or injecting unintended query operators.
**Prevention:** Always explicitly cast user input parameters like `req.query` and `req.body` to strings (e.g., `String(param)`) before calling string methods or creating regexes, and explicitly escape regex strings to prevent ReDoS. Preserve standard truthiness checks (`if (param)`) rather than switching to `if (param !== undefined)`.
