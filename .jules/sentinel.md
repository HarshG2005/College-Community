## 2026-04-13 - Prevent ReDoS and DoS via Explicit String Casting and Regex Escaping
**Vulnerability:** The application was vulnerable to Regular Expression Denial of Service (ReDoS) and Denial of Service (DoS) via query parameters (e.g., `company` and `type` in `server/routes/placements.js`). Unsanitized query parameters were passed directly to `new RegExp` and methods like `.toLowerCase()` without string casting.
**Learning:** In the absence of global security middleware or strict request validation, passing array or object payloads via query parameters (e.g., `?company[]=val` or `?type[]=a&type[]=b`) can cause server crashes (DoS) when string methods are called, or lead to ReDoS and NoSQL Injection.
**Prevention:** Always explicitly cast `req.query` and `req.params` values to strings (e.g., `String(param)`) before using string methods or building queries. When constructing a `RegExp` dynamically from user input, the input must first be string-cast and strictly escaped using a function like `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
