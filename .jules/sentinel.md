## 2025-01-31 - ReDoS and NoSQL Injection in Express Routes
**Vulnerability:** User input from `req.query` (`company`, `type`, `search`) was used directly in Mongoose queries, including inside `new RegExp(company, 'i')`. This exposed the application to ReDoS (Regex Denial of Service) and NoSQL Injection (since `req.query` properties can be objects, e.g., `?company[$ne]=val`). String methods like `.toLowerCase()` called on `type` would also crash the server if `type` was an object.
**Learning:** In Express, query parameters can be objects rather than strings. Directly using them in queries or string operations without type checking or casting leads to multiple classes of vulnerabilities. Express does not automatically cast query variables to strings.
**Prevention:** Always explicitly cast variables from `req.query` and `req.params` to strings (e.g., `String(req.query.param)`) before using them in string methods or queries. When constructing a regular expression from user input, strictly escape the input using `.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` to prevent injection of malicious regex patterns.
