## 2024-05-18 - NoSQL Injection and Type DoS in Express Routes
**Vulnerability:** User-supplied inputs (like `req.query`, `req.body`) are directly passed to string methods (like `.toLowerCase()`) or Mongoose queries (like `findOne`) without proper type checking or explicit string coercion. For example, `req.query.type.toLowerCase()` will crash the server if an array `?type[]=a` is passed. Similarly, object payloads (like `req.body.planId = { $ne: null }`) can bypass checks or cause NoSQL injection.
**Learning:** `express-validator`'s `.isEmail()` allows an array where the first element is an email to pass validation unless `matchedData` is used. Furthermore, Mongoose query operators can be passed in standard JSON body or parsed query objects.
**Prevention:** Always explicitly cast user inputs to strings (e.g., `String(input)`) before calling string methods or passing them into database queries to ensure they are primitives and to prevent DoS crashes or NoSQL object injection.
