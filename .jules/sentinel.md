## 2024-08-09 - [Express req.query Type DoS and NoSQL Injection]
**Vulnerability:** Type DoS, ReDoS, and NoSQL injection vulnerabilities exist across Express routes where `req.query` variables are passed uncast to string methods (like `.toLowerCase()`), `RegExp` constructors, or MongoDB queries (like `$text: { $search: query }`). An attacker can send an array or object in the query string (e.g. `?category[$ne]=val`), causing crashes (DoS) or unexpected database queries.
**Learning:** In Express, `req.query` and `req.body` values can be parsed as arrays or objects, unlike `req.params` which are always strings. Calling string methods directly on these properties without ensuring they are strings can cause Type Errors that crash the server, or lead to NoSQL injections.
**Prevention:** Always explicitly cast user-supplied input from `req.query` and `req.body` to strings using `String(value)` before calling string methods or passing them into MongoDB queries or `RegExp` constructors. Remember to also escape strings when passing to `RegExp` to prevent ReDoS.
