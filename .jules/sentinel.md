## 2024-08-05 - Type DoS via array payload bypass in express-validator
**Vulnerability:** The `/register` and `/login` routes in `server/routes/auth.js` suffered from a Type Denial of Service (DoS) vulnerability. By passing an array like `{"email": ["attacker@example.com", "other"]}`, an attacker could bypass `express-validator`'s `.isEmail()` (which only checks the first element of an array if `matchedData` is not used). When `req.body.email.toLowerCase()` was subsequently called, it caused the Node.js application to crash because Arrays do not have a `toLowerCase()` method.
**Learning:** `express-validator` does not inherently enforce type safety or strictly reject arrays for primitive validations unless explicitly configured or if `matchedData()` is used. Accessing user inputs from `req.body` or `req.query` without explicit string casting before calling string methods creates trivial crash vectors.
**Prevention:** Always explicitly cast user input to a String (e.g., `String(req.body.email)`) before calling string methods or passing it to database queries, ensuring unexpected types like Arrays or Objects are handled gracefully rather than crashing the process.
