## 2024-07-05 - [High] Express Route req.query Implicit Trust Vulnerability Pattern
**Vulnerability:** Across multiple routes (`events.js`, `notices.js`, `materials.js`, `placements.js`), properties of `req.query` (like `category`, `search`, `company`) were directly used in database queries (`$text` operations), string methods (`.toLowerCase()`), or passed to `new RegExp()` without validation or explicit type casting.
**Learning:** `req.query` properties in Express can be arrays or objects (e.g., `?category[]=tech` or `?search[$ne]=`). Directly calling `.toLowerCase()` on an array causes a Type DoS crash (`TypeError: category.toLowerCase is not a function`). Directly passing objects to NoSQL queries causes NoSQL Injection. Directly passing unescaped user input into `new RegExp()` causes ReDoS vulnerabilities.
**Prevention:** Always explicitly cast `req.query` and `req.body` properties to Strings (e.g., `String(category)`) before using them in string methods or database queries. For regex searches in Mongoose, always cast to String AND escape regex special characters (e.g., `String(company).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`) before passing them to `new RegExp()`.
