## 2024-05-24 - Unescaped RegEx and Uncasted Queries DoS
**Vulnerability:** NoSQL Injection and Regular Expression Denial of Service (ReDoS) via unescaped `req.query` parameters passed to `new RegExp`, as well as general DoS from calling `.toLowerCase()` on uncasted query parameters (which can be arrays or objects).
**Learning:** In Express, `req.query` properties can be strings, arrays, or objects. If a property is expected to be a string but is an object or array, calling string methods like `.toLowerCase()` will throw a TypeError, causing a 500 server error and potentially crashing the process if unhandled, leading to DoS. Additionally, passing user input directly into `new RegExp(input, 'i')` without escaping regex control characters allows attackers to inject complex regex patterns that cause catastrophic backtracking (ReDoS) and NoSQL injection attacks by matching unintended data.
**Prevention:** Always explicitly cast `req.query` and `req.params` parameters to strings (e.g., `String(param)`) before invoking string methods. To prevent ReDoS and NoSQL Injection, user input used in Mongoose queries via `new RegExp` must be strictly escaped before use (e.g., `String(input).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`).
