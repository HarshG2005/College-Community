## 2024-05-24 - [CRITICAL] Fix NoSQL Injection and ReDoS in placements route
**Vulnerability:** The `req.query.company` parameter was passed directly to `new RegExp(company, 'i')` without escaping, leading to a Regular Expression Denial of Service (ReDoS) vulnerability. Additionally, `req.query.type` and `req.query.search` were not cast to strings, allowing NoSQL injection via object payloads (e.g., `?type[$ne]=val`) and causing DoS when `.toLowerCase()` is called on an object.
**Learning:** In Express/Mongoose applications, `req.query` and `req.params` parameters must ALWAYS be explicitly cast to strings before being used in database queries or string methods to prevent NoSQL injection and application crashes. User input must also be escaped before being used in `new RegExp`.
**Prevention:** Always use `String(param)` to cast user input from the request. When using user input in a regular expression, escape it using `String(param).replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.
